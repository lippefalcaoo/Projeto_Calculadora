# Calculadora em Python 🧮

Um projeto duplo criado para praticar a transição da lógica de programação pura para o desenvolvimento de aplicações visuais em Python.

## 💻 Versão 1: Calculadora no Terminal (Atual)

A primeira fase do projeto é uma calculadora interativa que roda diretamente no terminal. Este código me ajudou a fixar os conceitos de:
- Lógica de programação
- Estruturas de repetição (`while`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Tratamento de entrada de dados e conversão de tipos (`float`)

### Funcionalidades do Terminal
O programa exibe um menu interativo e realiza as seguintes operações matemáticas básicas com números decimais:
- Soma
- Subtração
- Multiplicação
- Divisão (com tratamento para evitar erro de divisão por zero)

## 🎨 Versão 2: Interface Gráfica (Em breve!)

O próximo passo deste projeto é criar uma **versão 100% visual com Interface Gráfica (GUI)**. 
A ideia é pegar a mesma lógica matemática desenvolvida no terminal e conectá-la a botões, janelas e eventos visuais.

**O que vem por aí:**
- Interface moderna e clicável.
- Aprendizado sobre orientação a eventos.
- Utilização de bibliotecas visuais do Python (como Tkinter, CustomTkinter ou Flet).

## 🚀 Como executar a versão atual (Terminal)

### Pré-requisitos
Você precisa ter o [Python](https://www.python.org/downloads/) instalado no seu computador.

### Passo a passo
1. Clone este repositório no seu computador ou baixe o arquivo `.py`.
2. Abra o terminal na pasta onde o arquivo está salvo.
3. Execute o comando abaixo:

```bash
