# Calculadora em Python no Terminal 🧮

Um projeto simples de uma calculadora interativa que roda diretamente no terminal. Este foi o meu primeiro projeto para praticar lógica de programação, estruturas de repetição e condicionais em Python.

## 🛠️ Funcionalidades

O programa exibe um menu interativo e realiza as seguintes operações matemáticas básicas com números decimais:
- Soma
- Subtração
- Multiplicação
- Divisão (com tratamento para evitar erro de divisão por zero)

## 🚀 Como executar o projeto

### Pré-requisitos
Você precisa ter o [Python](https://www.python.org/downloads/) instalado no seu computador.

### Passo a passo
1. Clone este repositório no seu computador ou baixe o arquivo `.py`.
2. Abra o terminal na pasta onde o arquivo está salvo.
3. Execute o comando abaixo:

```bash
python calculadora.py
